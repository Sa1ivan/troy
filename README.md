# Гостевой дом «Троя»

Сайт подбора номеров на сезон 2027 года. Админка доступна на том же сайте после входа.

## Запуск демо

Нужен Node.js 20.9 или новее.

    npm ci
    npm run dev

Откройте [сайт](http://127.0.0.1:3000/). В отдельной вкладке откройте [вход для сотрудников](http://127.0.0.1:3000/admin/) и введите `admin` / `troy-demo`.

Для проверки выберите двухместный стандарт на 14–16 июня 2027 года. Заявка должна стоить 9 500 ₽. После подтверждения и внесения предоплаты 3 000 ₽ в брони останется 6 500 ₽. Используйте тестовое имя и телефон. Заявки, брони и оплаты сохраняются в браузере и доступны вкладкам одного сайта в том же профиле браузера.

## Рабочий журнал

Нужен Node.js 24 или новее. Перед запуском задайте переменные окружения сервера.

| Переменная | Значение |
| --- | --- |
| `TROY_MODE` | `live` |
| `TROY_ORIGIN` | Публичный адрес сайта с HTTPS, например `https://hotel.example`. Для локальной проверки подойдёт `http://127.0.0.1:3000`. |
| `TROY_DATA_FILE` | Абсолютный путь к файлу SQLite в закрытом для веб-доступа каталоге на постоянном диске. Пользователю сервера нужна запись в этот каталог. |
| `TROY_ADMIN_LOGIN` | Логин для входа сотрудников. |
| `TROY_ADMIN_PASSWORD` | Уникальный пароль от 16 символов. |

    npm ci
    npm run build
    npm start

Проксируйте публичный HTTPS-адрес на `127.0.0.1:3000`. При первом обращении к журналу сервер создаст SQLite-файл с фондом комнат и пустым журналом. Назначьте категории комнат второго корпуса в админке. Сотрудники работают с общими заявками, бронями и платежами по адресу `/admin/`. Гостевые заявки появляются в журнале после сохранения на сервере.

Перед публичным запуском сверьте с владельцем номерной фонд, тарифы сезона и условия бронирования. Категории комнат второго корпуса в новом демо показывают пример настройки.

## Демо на GitHub Pages

GitHub Actions публикует демо из ветки `main`. Откройте [сайт](https://sa1ivan.github.io/troy/) и [админку](https://sa1ivan.github.io/troy/admin/) в одном браузере. Действия в демо сохраняются в этом браузере.

Команда `npm run build:pages` создаёт статические файлы в `out/` для публикации по пути `/troy/`.

## Проверки

    npm run typecheck
    npm test
    npm run build
    npx playwright install chromium
    npm run test:e2e

Браузерные тесты сами запускают локальный сервер на порту 3213. Если dev-сервер уже работает, можно запустить их с его адресом.

    TROY_TEST_URL=http://127.0.0.1:3000 npm run test:e2e

Для проверки API и доставки заявки между профилями запустите рабочий режим с временным SQLite-файлом. Передайте тестам те же `TROY_ADMIN_LOGIN` и `TROY_ADMIN_PASSWORD`.

    TROY_TEST_URL=http://127.0.0.1:3000 \
      TROY_LIVE_TEST_URL=http://127.0.0.1:3000 \
      npm run test:e2e -- tests/live-api.spec.ts tests/live-booking.spec.ts
